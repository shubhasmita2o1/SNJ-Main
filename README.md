# Swastha Navjeevan

A modern, multilingual healthcare and wellness platform built with **React**, **Vite**, and a lightweight backend. The platform is designed to provide users with information about Swastha Navjeevan's mission, programmes, research, holistic wellness, and appointment/contact facilities through an immersive and responsive web experience.

---

## 🌐 Features

- Modern responsive UI
- Animated landing page
- Multilingual support
- Healthcare & wellness information
- Programme & Research pages
- Contact & Appointment section
- WhatsApp integration
- Smooth page transitions
- Scroll animations
- SEO optimized structure
- Mobile friendly design

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/shubhasmita2o1/SNJ-Main.git
```

Go to the project folder

```bash
cd SNJ-Main
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

The application will be available at

```
http://localhost:5173
```

---

## 📦 Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
